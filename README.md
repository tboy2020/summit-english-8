# Summit English 8 ✦

Master **Grade-8 English** — reading, vocabulary, grammar and argument — with a clear explanation after every answer. A clean, mature single-file PWA for a ~13–14-year-old. Cornerstone Studio · *Glory to God alone · AMHG*.

## What's inside
- **17 skills** across four strands:
  - **Reading (RL/RI.8)** — central idea, text evidence, inference, text structure, figurative language & theme (with short passages)
  - **Vocabulary (L.8.4/L.8.6)** — context clues, roots & affixes, precise word choice
  - **Grammar & Conventions (L.8.1/L.8.2)** — subject–verb agreement, verbals, active/passive voice, commas & semicolons, modifiers & mood, spot-the-error
  - **Argument Writing (W.8.1)** — claims vs facts, strongest evidence, counterclaims
- Multiple-choice with an **instant explanation** of *why* the answer is right; mastery = 4 in a row; per-strand dashboard.

Single `index.html` (ES5) + `manifest.json` + `sw.js` + `icon.svg`; progress in `localStorage`; installable + offline.

## Run / deploy
Open `index.html`, or serve the folder. For GitHub Pages: push to a public repo and enable Pages (`main`, root).
